# DIALECTICA V0.8 — Robust Information Under Model Misspecification

## Research question

Can an experiment that appears highly informative under the working model actually make the final inference worse when the working model is misspecified?

V0.8 implements finite-discrete versions of the AISTATS 2026 Expected Generalized Information Gain (EGIG) and a KL-instantiated Robust f-Information Measure (RFIM). Both require an explicit true data-generating model and a separate working inference model.

## Definitions

Let theta be a finite hypothesis, y an experiment outcome, d a candidate experiment, M* the true simulator, and M the working model used for inference. Both models share the same prior p(theta) in this implementation.

### Working-model EIG

    EIG_M(d) = E_{y ~ p_M(y|d)} [
        KL(p_M(theta|y,d) || p(theta))
    ]

This is the ordinary expected information gain under the assumed model.

### True EIG

    EIG_true(d) = E_{y ~ p_M*(y|d)} [
        KL(p_M*(theta|y,d) || p(theta))
    ]

This is an oracle diagnostic because the true model is generally unavailable in a real application.

### EGIG

    EGIG(d) = E_{(theta,y) ~ p_M*(theta,y|d)} [
        log(p_M(theta|y,d) / p(theta))
    ]

Equivalently:

    EGIG(d) = EIG_true(d)
              - E_{y ~ p_M*(y|d)} [
                    KL(p_M*(theta|y,d) || p_M(theta|y,d))
                ]

The second term is the expected posterior mismatch penalty. EGIG can be negative: under the true data-generating process, the working procedure may move its belief farther from the correct posterior than the prior baseline.

### KL-instantiated robust f-information

    I*_KL(d) = EIG_true(d)
               - E_{theta ~ p(theta)} [
                    KL(p_M*(y|theta,d) || p_M(y|theta,d))
                ]

This criterion penalizes conditional likelihood mismatch. It is distinct from EGIG because it measures model-component error rather than only the final posterior mismatch. Under the shared-prior setup, the likelihood penalty also includes predictive-marginal mismatch; therefore it can be more conservative.

## Implementation

- dialectica/v08.py: finite categorical true/working model pair, EIG under each model, EGIG, posterior mismatch penalty, KL likelihood penalty, RFIM-KL, decomposition check, and strategy selection.
- dialectica/benchmark_v08.py: deterministic synthetic stress test with paired seeds.
- tests/test_v08.py: decomposition, sign, support, validation, selection, and reproducibility tests.

The implementation rejects support violations that would make posterior KL or EGIG infinite. It does not silently clip these cases.

## Synthetic stress test

Prior: P(A) = P(B) = 0.5.

Four candidate designs:

1. overconfident_misspec: the true model is only weakly informative, but the working model claims a 99%/1% signal.
2. spurious_signal: the true process is independent of the hypothesis, while the working model invents a 90%/10% signal.
3. calibrated_signal: true and working models agree on a 75%/25% signal.
4. strong_calibrated_signal: true and working models agree on an 85%/15% signal.

The simulator samples the hidden hypothesis and outcome from the true model. The decision-maker updates using the working model. Five selection strategies are compared: random, working-model EIG, oracle true EIG, EGIG, and RFIM-KL.

### Analytical acquisition values

| Candidate | Working EIG | True EIG | EGIG |
|---|---:|---:|---:|
| Overconfident mismatch | 0.6371 | 0.0201 | -1.1550 |
| Spurious signal | 0.3681 | 0.0000 | -0.5108 |
| Calibrated signal | 0.1308 | 0.1308 | 0.1308 |
| Strong calibrated signal | 0.2704 | 0.2704 | 0.2704 |

The working-model EIG ranks the overconfident mismatch first. EGIG ranks the strong calibrated signal first.

### Monte Carlo results

5,000 runs; seed 20261123; common per-run truth and observation random seeds across strategies.

| Strategy | Selected design | Accuracy | Mean log loss | Mean Brier | Mean posterior KL |
|---|---|---:|---:|---:|---:|
| Random | Random | 68.34% | 0.9864 | 0.5461 | 0.4124 |
| Working EIG | Overconfident mismatch | 61.08% | 1.7985 | 0.7630 | 1.1751 |
| Oracle true EIG | Strong calibrated | 85.44% | 0.4151 | 0.2488 | 0 |
| EGIG | Strong calibrated | 85.44% | 0.4151 | 0.2488 | 0 |
| RFIM-KL | Strong calibrated | 85.44% | 0.4151 | 0.2488 | 0 |

In this constructed example, the working EIG chooses an experiment that is more confident but less accurate than random selection. EGIG avoids that failure. This is a demonstration of the mechanism, not evidence of general performance: the candidate set is deliberately designed to expose model misspecification, and the true model is known to the simulator.

## Important limitations

- The true model is supplied by the benchmark; real systems do not have an oracle.
- The benchmark is finite and categorical; no continuous dynamical system or approximate inference algorithm is reproduced.
- EGIG and RFIM-KL are exact only for the supplied likelihood tables and shared prior.
- EGIG and RFIM-KL coincide on the symmetric benchmark examples. A separate unit test now checks an asymmetric predictive-marginal case where the criteria differ. The main Monte Carlo benchmark still needs a factorial design that varies this source of mismatch.
- Results do not establish that EGIG is universally superior. It is a criterion for specified misspecification settings, not a universal truth detector.
- No real LLM agents, retrieval, LangGraph workflow, or 3D interface are included.

## Next research tasks

1. Add cases where conditional likelihood mismatch and predictive-marginal mismatch differ, separating EGIG from RFIM-KL.
2. Add prior misspecification and inference approximation errors.
3. Test sensitivity to unknown true-model ensembles rather than a single oracle.
4. Compare EGIG, RFIM-KL, robust EIG, and decision regret across a factorial misspecification grid.
5. Evaluate an ensemble of plausible true models. V0.8 now includes weighted-mean ensemble EGIG (equivalent to EGIG under the mixture true model for a fixed working model) and a worst-case EGIG sensitivity score. The worst-case score is a conservative extension, not the canonical EGIG criterion.
5. Reproduce R-IDeA in its original regression/active-learning setting before attempting to transfer it to debate or hypothesis selection.
6. Add paired bootstrap confidence intervals and a held-out family of data-generating processes.
