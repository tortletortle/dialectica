## Paper equations

The paper defines the representative-information acquisition function as

    R-I(xi_t) = EIG(xi_t) * [1 - lambda * MMD^2(H_(t-1) union {xi_t}, D_test)
                                         / MMD^2(H_(t-1), D_test)]

The paper's Appendix D explicitly defines the discrepancy as **squared empirical MMD** using the biased estimator and an RBF kernel with bandwidth sigma=1. The implementation therefore uses MMD^2, not sqrt(MMD^2), in the acquisition ratio.

The proxy objective in Equation (11) is

    L(g) = mean_i (g(x_i) - y_i)^2
           + mean_i max(0, tau - |f_hat(x_i) - g(x_i)|)

and Equation (12) defines

    R-IDeA(xi_t) = R-I(xi_t) * sigmoid((|f_hat(xi_t)-g(xi_t)| - tau) / kappa).

The paper fixes kappa=1 in its experiments. The best-in-class predictor f_bar is the minimizer of expected squared prediction error over the target/test distribution, not the true data-generating function itself.

## Polynomial benchmark specification from Appendix D.1

- DGP: y = 1 + 2x - 0.5x^2 + epsilon, epsilon ~ Normal(0, 0.1).
- Well-specified learner: quadratic polynomial with features [1, x, x^2].
- Misspecified learner: linear polynomial with features [1, x].
- Test/design distribution: Uniform(-4, 4).
- Number of independent runs: 20.
- Total designs per run: T=10.

Appendix E.1.3 adds a high-misspecification cubic DGP:

    y = 1 + 2x - 0.5x^2 + 0.2x^3 + epsilon.

The paper reports that tau=0.5 performs best in its polynomial tau sweep. It also explicitly warns that lambda=0.25 can make R-I and R-IDeA worse than Random in the severely misspecified cubic case. Hyperparameter sensitivity is therefore part of the method, not an optional extra.

## Supplementary implementation findings

The fixedmodel code path has several details that are easy to miss:

1. compute_mmd returns the biased **squared** MMD expression with RBF sigma=1.
2. Candidate set size is 60; the reference/test grid uses 100 points over [-4,4]. Candidate order is randomly permuted before argmax.
3. The fit_g_mle_with_margin proxy is initialized at zero, is linear (b0 + b1*x), and uses Adam for 200 steps at learning rate 0.01. Its margin threshold is hard-coded to 2.0 and alpha defaults to 1.0.
4. The DeA threshold tau is separately parsed from the method name; when absent, the code can use an empirical 80th-percentile threshold. The smooth-kappa setting defaults to a truthy value that acts as kappa=1; explicitly setting it to None selects a hard threshold.
5. The main runner sets num_rounds=5, while Appendix D.1 specifies T=10 total designs. This reproduction follows the paper's stated T=10, not that runner default.
6. The source runner assigns BEST_BETA=true_beta in the misspecified case. That is the true polynomial coefficient vector, not the best-in-class projection f_bar for a linear learner. The error-decomposition helper also hard-codes the quadratic best-linear coefficients (-1.672, 2.0), which do not remain correct for the cubic DGP. V0.9 computes the L2 projection of the true DGP onto the learner class under the Uniform(-4,4) target distribution and uses that for the oracle diagnostic.
7. The source test-phase MSE compares predictions with noisy observations. V0.9 reports noiseless conditional-mean test risk and also reports its exact expected noisy-observation counterpart by adding the known noise variance 0.01. This removes Monte Carlo test-noise variance without changing the expected ranking.

## V0.9 implementation choices and deviations

- Posterior and EIG: exact conjugate Gaussian linear-regression updates and analytic EIG, rather than the authors' Pyro/PyTorch Monte Carlo EIG and NUTS posterior approximation. This is exact for the finite-dimensional Gaussian linear model used here, but it is not bit-for-bit reproduction of their stochastic implementation.
- Proxy: zero-initialized linear proxy, 200 Adam steps, lr=0.01, alpha=1, matching the supplementary regression path. The proxy basis remains linear in the well-specified quadratic control because that is what this code path does; the oracle uses the correct learner-class projection.
- Main configuration: lambda=0.5, DeA tau=0.5, proxy-margin tau=2.0, kappa=1, squared MMD, 60 candidates, 100 reference points, 20 runs, 10 total designs.
- A second configuration sets proxy-margin tau equal to the DeA tau, following a literal shared-tau reading of Equations (11) and (12). The supplementary implementation's separate margin threshold is retained as the main code-faithful path.
- Random designs are sampled from the 0.1-spaced grid, matching the supplementary polynomial runner.

## Interpretation limits

This is an equation-level reproduction with explicit deviations, not a claim of exact numerical replication. The benchmark is a one-dimensional polynomial regression problem; it does not establish that R-IDeA transfers to language-model debate, multi-agent reasoning, or real-world scientific discovery.
