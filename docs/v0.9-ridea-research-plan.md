# DIALECTICA V0.9 Research Plan — Faithful R-IDeA Reproduction

## 1. Why this must be a separate benchmark

Tang, Sloman, and Kaski (AISTATS 2026) derive R-IDeA for Bayesian optimal experimental design / active learning in a regression setting. The method chooses continuous design inputs and trains a proxy predictor. It is not a drop-in score for discrete debate stances or categorical hypothesis votes.

DIALECTICA should first reproduce the paper's regression setting, validate the acquisition function, and only then test whether a defensible analogue exists for selecting debate probes or evidence requests.

## 2. Paper-derived mathematics

The paper decomposes test generalization error into:

    R_test(f_hat) = B + C + A

where B is misspecification bias, C is estimation error, and A is their interaction (error amplification / de-amplification).

For selected design history h_(t-1), candidate design xi_t, and target/test distribution d_test, the R-I acquisition is:

    R-I(xi_t) = EIG(xi_t) *
      [1 - lambda * MMD(h_(t-1) union {xi_t}, d_test)
                   / MMD(h_(t-1), d_test)]

The paper uses squared empirical MMD with an RBF kernel:

    MMD^2(P,Q) =
      mean(k(p_i,p_j)) + mean(k(q_i,q_j))
      - 2 * mean(k(p_i,q_j))

    k(x,y) = exp(-||x-y||^2 / (2*sigma^2))

The paper's reported numerical experiments use sigma = 1. The implementation must record whether it uses MMD or MMD-squared in the ratio; these are not interchangeable.

R-IDeA multiplies R-I by a smooth de-amplification factor:

    DeA(xi_t) = sigmoid((|f_hat(xi_t) - g(xi_t)| - tau) / kappa)

    R-IDeA(xi_t) = R-I(xi_t) * DeA(xi_t)

The proxy g is trained to fit collected observations while maintaining a margin of disagreement from f_hat:

    L(g) = mean((g(x_i) - y_i)^2)
           + mean(max(0, tau - |f_hat(x_i) - g(x_i)|))

The paper motivates g as a proxy aligned with the best-in-class predictor while retaining disagreement with the current fitted predictor. It does not observe the true DGP or the true best-in-class predictor directly.

## 3. Faithful first reproduction

Use the paper's one-dimensional polynomial-regression setup first.

- Candidate design domain: x in [-4, 4].
- Target/test input distribution: Uniform(-4, 4).
- True DGP: y = 1 + 2x - 0.5x^2 + epsilon, epsilon ~ Normal(0, 0.1).
- Misspecified working model: linear regression f(x) = beta_0 + beta_1*x.
- Well-specified control: quadratic regression f(x) = beta_0 + beta_1*x + beta_2*x^2.
- Sequential design budget: 10 selected inputs per run, matching the paper's polynomial-regression setting.
- Evaluation: test MSE against the known simulator, MMD between selected design distribution and target distribution, and design-selection traces.
- Repetitions: at least 20 independent seeds for an initial replication; increase repetitions for confidence intervals.

Baselines:
1. Random selection from target distribution.
2. BAD / ordinary EIG.
3. R-I.
4. R-IDeA using a learned proxy g.
5. R-IDeA-oracle using the true best-in-class predictor only as an upper-bound diagnostic, never as a deployable method.

Ablations:
- EIG only vs EIG + representativeness vs EIG + representativeness + de-amplification.
- Sweep lambda, tau, and kappa.
- Compare MMD and MMD-squared variants explicitly.
- Test both well-specified and misspecified model classes.
- Add a stronger misspecification case with a cubic term in the DGP.

## 4. Implementation safeguards

1. The denominator MMD(history, target) can be zero or numerically tiny. Define and test a principled initialization and epsilon policy; do not silently divide by zero.
2. MMD bandwidth strongly affects the distance. Record sigma, kernel, sample sizes, and whether biased or unbiased estimator is used.
3. The proxy objective is non-convex because of the absolute-value margin term. Compare multiple initializations and record convergence; do not claim the proxy has converged merely because an optimizer stopped.
4. The paper itself reports that tau selection is difficult and that unsuitable settings can make R-IDeA perform worse than R-I or Random in some settings. Hyperparameter sensitivity is part of the replication, not an optional appendix.
5. Preserve negative acquisition scores if the paper's formula yields them; document the selection policy when all candidate scores are negative.
6. Separate oracle diagnostics from deployable methods.
7. Use fixed candidate grids and paired random seeds across strategies.

## 5. Possible transfer to DIALECTICA — research hypothesis only

A possible mapping is:
- x: a task condition, evidence query, adversarial probe, or deployment context;
- f*: actual task outcome under a benchmark oracle;
- f_hat: current agent/system prediction;
- g: a separately trained proxy for the best-in-class predictor or a calibrated reference model;
- d_test: the intended deployment distribution of tasks.

Potential benefit: prevent the debate engine from selecting only unusual, high-disagreement prompts that do not represent the actual task distribution.

Critical unresolved issue: in language-model debate, the quantities f*, f_bar, and f_hat may be vector-valued, categorical, or text-valued. The regression de-amplification term does not automatically generalize to these settings. A valid transfer requires an operational outcome metric, a defensible target distribution, a calibrated proxy, and a controlled benchmark.

No V0.9 R-IDeA implementation should be called faithful until the regression reproduction passes the baselines and ablations above.

## 6. Acceptance criteria

- Reproduce the direction of the paper's key result under the specified misspecified regression setting.
- Demonstrate the well-specified control, where robustness corrections should not create unjustified degradation.
- Show sensitivity to lambda and tau, including settings where R-IDeA loses to simpler baselines.
- Report mean and uncertainty intervals across paired seeds.
- Publish complete configuration, raw run-level metrics, and plots.
- State deviations from the paper explicitly.
