# DIALECTICA V0.7 — Bayesian Model Discrimination Prototype

## Scope

V0.7 implements a finite, discrete experiment-selection core. It compares candidate experiments under explicitly supplied hypothesis priors, outcome likelihoods, and (for EVSI) decision utilities. It is a research prototype, not a validated scientific-discovery agent.

## Implemented quantities

For hypotheses H and experiment e with outcome likelihood P(y | H, e):

- **Expected information gain (EIG):** I(H;Y | e) = H(H) - E_Y[H(H | Y,e)], in nats. Exact for the supplied finite model.
- **Expected Bayes classification error:** E_Y[1 - max_h P(h | Y,e)], using 0–1 loss.
- **EVSI:** expected optimal post-observation decision utility minus current optimal decision utility. Requires an explicit action-by-hypothesis utility table.
- **EIG/cost and EVSI/cost:** budget-normalized ranking heuristics; cost must be meaningfully calibrated.
- **Robust EIG:** minimum EIG across caller-supplied prior scenarios. This tests prior sensitivity only; it is not a complete robust Bayesian active-learning method and does not protect against wrong likelihoods.
- **Predictive-surprise diagnostic:** flags an observed outcome with low prior-predictive probability. The threshold is a screening heuristic, not a calibrated goodness-of-fit test.
- **Simple-hypothesis mean separation:** minimum pairwise squared mean difference divided by measurement variance. This is a diagnostic inspired by T-optimality, not the full classical T-optimal criterion for composite models with nuisance parameters and optimized design measures.
- **Pareto frontier:** retains experiments not dominated simultaneously on EIG, EVSI, mean pairwise total-variation separation, and cost.

## Open-world handling

The add-unknown-hypothesis helper adds an explicit residual hypothesis H_other with caller-supplied likelihoods for every candidate experiment. This is not automatic unknown-hypothesis discovery. The model builder must propose and justify the residual predictive distribution. If all hypotheses assign near-zero probability to an observation, the posterior-predictive diagnostic can flag possible model mismatch for review.

## Synthetic benchmark design

- Hidden truth: cpu, memory, gpu, or other, with probabilities 0.30, 0.30, 0.30, and 0.10.
- Five candidate interventions: CPU frequency, memory bandwidth, GPU swap, workload scale, and cache flush.
- Each intervention has three possible outcomes: improve, unchanged, or worse.
- Three experiments are selected without replacement per run.
- 5,000 runs per condition, seed 20261123.
- **Closed-world condition:** inference is restricted to CPU/memory/GPU although the simulator can generate other cases.
- **Explicit-unknown condition:** inference includes an other hypothesis with a specified predictive distribution.
- Strategies: random, EIG, expected Bayes error, EIG/cost, EVSI/cost, and simple mean separation.

The simulator's likelihoods are hand-authored and known to the simulation environment. They are not measured hardware data. Results test implementation behavior under this toy model only.

## Preliminary results

| Condition | Strategy | Accuracy | Mean log loss | Unknown recall |
|---|---|---:|---:|---:|
| Closed world | Random | 65.84% | 3.2973 | 0% |
| Closed world | EIG/cost | 71.52% | 3.1071 | 0% |
| Closed world | Expected Bayes error | 71.44% | 3.1762 | 0% |
| Explicit unknown | Random | 66.74% | 0.8598 | 30.94% |
| Explicit unknown | EIG | 72.16% | 0.6878 | 33.20% |
| Explicit unknown | Expected Bayes error | 72.66% | 0.7111 | 32.99% |
| Explicit unknown | EIG/cost | 73.12% | 0.6841 | 40.78% |
| Explicit unknown | EVSI/cost | 71.98% | 0.7163 | 40.98% |
| Explicit unknown | Simple mean separation | 53.10% | 1.0330 | 38.11% |

These are descriptive Monte Carlo results from one fixed synthetic benchmark and seed. They are not evidence of general superiority. The simple mean-separation baseline is deliberately only a crude simple-hypothesis proxy; its weak result must not be interpreted as a failure of classical T-optimal design.

The closed-world log loss is high because the true other class has zero probability in the inference model; probabilities are clipped only for finite reporting. This is intentional evidence of the cost of forcing a closed-world answer, not a calibrated comparison of log loss across differently specified hypothesis spaces.

## Limitations and next experiments

1. Vary the unknown-hypothesis prior mass and residual likelihood family.
2. Deliberately misspecify likelihoods and test predictive-surprise alarms.
3. Change the truth prior, observation noise, experiment costs, and budget.
4. Add paired confidence intervals or bootstrap comparisons across common task seeds.
5. Compare against a faithful implementation of classical T-optimal design on a continuous/composite-model benchmark.
6. Add adaptive hypothesis generation from residual patterns, with independent validation to prevent post-hoc overfitting.
7. Replace synthetic likelihoods with measured task data before making claims about real decisions.
